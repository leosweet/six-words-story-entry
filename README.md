## The story

> She left the light on. Forever.

Six words, one whole life of waiting: she leaves a light on for someone who never comes home — and keeps leaving it on.

## How it works

`main.ts` (Node 22) writes the story to `/output/entry.txt`. The program is fully deterministic: it writes the same bytes on every run, with no input, no network, and no randomness.

```sh
node main.ts
cat /output/entry.txt
```
